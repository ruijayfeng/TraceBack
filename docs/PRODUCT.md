# TraceBack 产品说明（UI 视角）

TraceBack（智溯）是面向 SOC/安全研究的安全告警研判工作台：把原始设备告警归一化、去重、关联成安全事件，重构攻击链，并用可回溯证据与 AI 解释支持调查。

## 用户与任务

- **SOC 分析员**：从 45k+ 告警中快速定位需要调查的事件，确认成员告警、实体、攻击链方向，形成可复核结论。
- **算法/数据工程师**：复核关联评分诊断，确认“0 条关联边”是严格证据准入而不是漏召回。
- **论文/评测读者**：在离线快照上复现实验，逐条追溯 claim → node/edge/alert/pointer。

## 信息架构

URL 是唯一状态源：`analysis_id`、`incident_id`、列表筛选（`page`、`page_size`、`kind`、`sort`、`severity`、`q`、`entity`、`start_time`、`end_time`）、详情深链（`node_id`、`edge_id`、`timeline_page`、`evidence`）。刷新/分享/前进后退都恢复同一视图。

1. **欢迎/分析入口**：分析 ID 输入、最近分析（后端 `/analyses` + 本机 localStorage 双通道）。
2. **安全事件工作台**：冻结快照状态、8 个投影计数、去重诊断、评分诊断（可折叠）、三类分布（来源/等级/类别）、事件列表（服务端搜索/实体/UTC 时间筛选/排序/分页/CSV）、主 CTA。
3. **事件详情**：摘要作页标题，事件类型/严重度/状态/攻击链状态 badge；页内导航（概况、攻击链、证据、时间线、AI 研判）；可观测字段与证据入口。
4. **攻击链**：算法构造的节点/有向边、置信分、拖拽平移与 Ctrl/⌘+滚轮缩放、移动端纵向布局、节点/边详情与证据。
5. **时间线**：全事件 UTC 范围刻度、当前页对象 marker、缩放、表格精确微秒时间、节点/告警联动。
6. **证据抽屉**：桌面右侧/移动底部 Sheet；对象面包屑与完整 ID 复制；可搜索支撑告警（来源/时间/规则）；绑定指针、字段来源、实体、raw_alert 惰性读取。
7. **AI 研判**：已保存报告优先；生成/取消/45s 超时/失败重试；重新生成二次确认；已验证 claim 分区（摘要、发现、攻击过程、ATT&CK、实体、风险、建议）；长文本折叠；0 引用证据禁用；诊断/被拒绝内容折叠隔离；JSON/Markdown 导出。

## 状态与文案

- **加载**：首屏 skeleton + 既有加载文案；筛选/翻页保留旧数据（stale-while-revalidate），不整块空白。
- **错误**：中文标题 + 原始 code + 重试；快照、AI、证据分别报错，不互相拖黑整页。
- **空**：区分“未提供/未生成/无匹配/当前页为空”；空态给出清除筛选/重新生成/下一步行动。
- **AI 边界**：`已拒绝 ≠ 已验证`；确定性模板不等于 AI 成功；ATT&CK 只展示目录校验通过的映射。
- **安全**：不渲染未转义 HTML；raw_alert 默认折叠、展开后才序列化；不请求 labels.csv/evaluation。

## 非目标

- 不做实时告警流、不写入/修改后端快照、不做自动处置。
- 不把 AI 文本当作事实来源；不新增无证据的步骤/技术映射。
- 不以装饰动效、玻璃拟态或高饱和渐变替代证据层级。

## 成功标准（UI）

- 768/390 无页面级横向溢出；所有核心操作可键盘完成；证据抽屉是真正的 dialog。
- 45k 事件的列表/详情在常用视口流畅；分页/筛选/搜索 URL 可分享。
- axe 0 violations（核心页面 + 抽屉）；detector 0 findings；typecheck/Vitest/Playwright/build 全绿。
