# 工作台页面与交互

工作台使用浅色背景、蓝色主色和顶部模块导航。首页展示摘要，完整数据通过独立页面、标签与分页访问，避免把完整调查流程堆叠成长页。

| 模块 | 地址 | 内容 |
| --- | --- | --- |
| 态势总览 | `/` 或 `/?view=overview` | 6 个真实指标、告警时间分布、关系决策分布、重点链的前 5 个观测阶段、来源分布、4 条链摘要 |
| 安全告警 | `/?view=alerts` | 当前快照的阶段成员告警索引，每页 10 条；搜索 ID 或阶段行为、按阶段来源/行为筛选、查看原始告警 |
| 攻击场景 | `/?view=scenes` | 按 community_id 展示调查分组，每页 10 条，进入关联攻击链 |
| 攻击链 | `/?view=stages` | 左侧链索引；右侧切换攻击流程、阶段列表、关系列表、全分析拒绝建边审计 |
| 证据追溯 | `/?view=evidence` | 阶段、已接受关系、拒绝建边三个分类，每页 10 条；抽屉内核对见证告警和字段指针 |
| 分析记录 | `/?view=records` | 分析 ID、算法版本、封存状态与统计口径 |

## 地址与状态

- `analysis_id` 保留当前快照；未指定时读取目录默认分析。
- `chain_id` 指定要打开的链。总览摘要的“查看”进入对应链，不再丢失所选链。
- 攻击链页的 `panel=graph|timeline|relations|audit` 在刷新后恢复当前视图。
- 独立列表的 `q`、`source`、`behavior`、`page` 保存筛选和页码；筛选变更回到第一页。
- 证据页的 `kind=stages|relations|rejected` 保存分类。
- 浏览器前进、后退可切换模块；模块内的筛选与标签通过 replaceState 更新当前地址。

## 展示边界

当前正式快照为 125 条告警、15 个阶段、12 条已接受关系和 7 条链结构；历史快照保持独立。总览时间序列按照观测时间排列，不绘制推测的因果箭头；完整攻击图保留实际方向与无向关系。

告警索引的来源、行为来自所属阶段，单条告警的准确字段通过原始记录核对。尚无数据支持的风险评分、处置状态、ATT&CK 战术分布不作为正式指标展示。

手机保留全部模块导航；关系和来源分布按需展开，摘要表仅保留链、阶段数、告警数与操作。长表在各自容器内横向滚动，完整攻击图支持缩放、适合宽度与查看全图。
