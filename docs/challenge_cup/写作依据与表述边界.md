## 允许拔高的叙事表达

1. “面向实战研判需求”：指设计面向实际调查问题，尚无生产客户实战效果证明。
2. “可验证的智能安全研判能力”：是对分层算法、解释模块和证据机制的整体定位，不代表最新正式链已经完成外部大模型端到端验收。
3. “提出分层攻击链重构方法”和四项“创新点”：为项目级工程与方法贡献的归纳，未开展穷尽性文献查新，不宜追加“全球首创”“国内唯一”“国际领先”。
4. “减少重复查找”“有望提高交接效率”“具备应用潜力”：属于机制推断与应用预期，尚无人员对照实验、试点工时或客户收益证明。

这些属于定位与价值叙事的适度包装。正文没有虚构处理速度、客户、部署、收入或检测效果。

## 特别保留的能力边界

- Attack Step 为离线原型，候选边界修复只达到 PARTIAL，仍存在跨真值污染与召回损失，未写成已正式接入。
- 当前有解释、校验和报告工程模块；新正式阶段链的完整解释联调与外部模型效果未完成验收。
- 正式关系模型使用 Evidence Claim / Context / Trace，不能沿用历史 v1 “共享 session 即强关联”的写法。
- Chain 是有效关系图的连通分量，包含孤立阶段；不等于完整因果路径，也不等于已确认的独立安全事件。
- 当前工作台以离线快照为主，来源分布不是设备在线率，时间分布不是实时监控。
- 未编写“效率提升 90%”“准确率 99%”“百万级实时处理”“已商业化”等无依据说法。
